# 洗好沒 (CYUT-DormWash-Realtime)

朝陽科技大學第二宿舍與天威智生活即時洗衣房狀態看板工具。

## 🌟 功能特點
- ⚡ **即時狀態同步**：基於 Firebase Realtime Database，即時顯示各棟別機台運轉與剩餘時間。
- 📍 **GPS 250m 地理圍欄**：自動驗證使用者是否在宿舍範圍內，確保現場控制權限。
- 🏢 **雙軌棟別適配**：自動切換第二宿舍（含床號）與天威智生活（純房號）輸入模式。
- 🌗 **雙色主題支援**：提供深色/淺色模式動態切換並記憶偏好（預設淺色模式）。
